详细描述

提供基于 rapidyaml 的高性能 YAML 解析、树访问、类型转换和文件读写功能

Node 是共享底层 YAML 树所有权的轻量句柄。子节点可安全脱离根节点保存，但同一棵树不提供内部线程同步。
