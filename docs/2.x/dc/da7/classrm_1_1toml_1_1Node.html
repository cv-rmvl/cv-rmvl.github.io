详细描述

共享底层节点树所有权的只读节点句柄

  • 拷贝仅共享节点树所有权，不复制节点树，子节点可独立于根句柄存活
  • 默认构造、查找失败或移出后的句柄无效，可用 valid() 或显式布尔转换判断
  • 布尔转换只判断节点有效性，保存 false 的布尔节点仍是有效节点
  • 节点树不可修改，同一棵节点树支持多个线程并发只读访问
  • keys() 返回的键名视图在底层节点树最后一个有效句柄销毁前有效

◆ read()

template<typename T>
bool rm::toml::Node::read ( T & value) const

读取节点并转换为指定的 C++ 类型

模板参数
T支持 std::string、bool、整数、浮点、枚举、Date、Time、DateTime、std::optional、 std::vector、std::array、以 std::string 为键的 std::map/std::unordered_map，以及 ADL 自定义类型
参数
[out]value转换结果，返回 false 时保持其原值不变
返回
转换成功返回 true，节点类型不符、数值越界或容器元素转换失败返回 false
  • 严格区分字符串、整数、浮点和布尔，不进行字符串到数字或整数到浮点的隐式转换
  • 整数转换检查目标类型范围，枚举通过其底层整数类型转换，不检查是否为已声明的枚举项
  • 浮点转换检查有限值是否超出目标类型范围，允许精度损失，保留无穷和 NaN
  • std::array 要求节点数组长度完全匹配，容器元素递归使用相同的转换规则
  • 无效节点读取为 std::optional 时会清空目标并返回 true，有效节点按其包含的类型转换
  • 自定义类型需能默认构造，在其命名空间提供 bool toml_decode(const rm::toml::Node &, T &) 解码在临时对象上完成，返回 false 时不覆盖调用方对象
    注解
    本函数不捕获内存分配异常或用户自定义解码函数抛出的异常

◆ loads

Node loads ( std::string_view source,
Error * error = nullptr )
friend

从内存中的 UTF-8 文本解析 TOML 1.0 配置

参数
[in]sourceTOML 文本，不要求以空字符结尾
[out]error可选的错误输出，默认为 nullptr，成功时清空已有错误
返回
成功时返回共享节点树所有权的 Table 根节点，空文本返回空 Table，失败返回无效节点

编码或语法错误、重复键和非法表定义等问题通过返回值和 ErrorCode::Parse 报告，不抛出异常

注解
  • 解析完成后不依赖 source 的内存，调用方可以释放或修改原始文本
  • 内存分配失败等标准库异常不在此错误协议内，本函数不保证 noexcept
