详细描述

提供 TOML 1.0 配置加载、只读节点访问和 C++ 类型转换功能

  • load() 从文件加载，loads() 从 UTF-8 文本加载，成功时均返回 Table 类型的根节点，失败返回无效节点
  • TOML 不包含 null 类型，Undefined 仅用于表示无效节点句柄

RMVL_EXPORTS Node rm::toml::load ( std::string_view path,
Error * error = nullptr )

#include <rmvl/core/toml.hpp>

从文件加载并解析 TOML 1.0 配置

参数
[in]path文件路径，相对路径以进程当前工作目录为基准，不允许包含空字符
[out]error可选的错误输出，默认为 nullptr，成功时清空已有错误
返回
成功时返回共享节点树所有权的 Table 根节点，空文件返回空 Table，失败返回无效节点
  • 路径或文件读写问题对应 ErrorCode::Io，编码、语法或定义冲突对应 ErrorCode::Parse
  • 这些加载错误通过返回值和 error 报告，不抛出异常
    注解
  • 返回的节点不引用 path 的内存，底层节点树由节点句柄共享持有
  • 内存分配失败等标准库异常不在此错误协议内，本函数不保证 noexcept
    参见
    loads()

◆ loads()

RMVL_EXPORTS Node rm::toml::loads ( std::string_view source,
Error * error = nullptr )

#include <rmvl/core/toml.hpp>

从内存中的 UTF-8 文本解析 TOML 1.0 配置

参数
[in]sourceTOML 文本，不要求以空字符结尾
[out]error可选的错误输出，默认为 nullptr，成功时清空已有错误
返回
成功时返回共享节点树所有权的 Table 根节点，空文本返回空 Table，失败返回无效节点

编码或语法错误、重复键和非法表定义等问题通过返回值和 ErrorCode::Parse 报告，不抛出异常

注解
  • 解析完成后不依赖 source 的内存，调用方可以释放或修改原始文本
  • 内存分配失败等标准库异常不在此错误协议内，本函数不保证 noexcept
